# Data Dictionary — Pet Insurance Claims Analytics (Synthetic)

> **All data in this project is synthetic**, generated by `src/generate.py`
> with fixed seed `20261012`. No real policyholders, pets, insurers, or
> medical records are represented.

## Tables

### `policies` — one row per synthetic policy (120,000 rows)

| Column | Type | Description |
|---|---|---|
| `policy_id` | TEXT | Primary key, `POL-000000` … `POL-119999` |
| `brand` | TEXT | Synthetic brand: `PawGuard`, `VetShield`, `CompanionCare` |
| `species` | TEXT | `dog` (72%) / `cat` (28%) |
| `breed` | TEXT | 15 dog breeds + 5 cat breeds (see `src/config.py`) |
| `breed_size` | TEXT | `giant` / `large` / `medium` / `small` (drives severity) |
| `age` | INT | Pet age in years at policy effective date, 0–15 |
| `age_bin` | TEXT | `0-1`, `2-3`, `4-6`, `7-9`, `10-12`, `13+` |
| `state` | TEXT | 12 states (CA, TX, FL, NY, IL, PA, OH, GA, NC, MI, WA, AZ) |
| `region` | TEXT | Census-style region derived from state |
| `density` | TEXT | `urban` / `suburban` / `rural` |
| `territory` | TEXT | `region-density`, e.g. `West-urban` (12 territories) |
| `effective_date` | DATE | Policy effective date (2018-07-01 … 2026-06-30) |
| `exposure_years` | REAL | Full tenure in years (may extend outside the modeling window) |
| `in_window_exposure_years` | REAL | Exposure inside 2019-01-01 … 2026-12-31 (GLM offset) |
| `lam_annual` | REAL | **Synthetic truth**: annual claim rate incl. unobserved heterogeneity |
| `expected_claims` | REAL | `lam_annual × in_window_exposure_years` |
| `annual_premium` | REAL | Synthetic annual premium (rating factors + filed rate trend, scaled so book LR = 68%) |
| `earned_premium` | REAL | `annual_premium × in_window_exposure_years` |

### `claims` — one row per synthetic claim (exactly 200,000 rows)

| Column | Type | Description |
|---|---|---|
| `claim_id` | TEXT | Primary key, `CLM-0000000` … |
| `policy_id` | TEXT | FK → `policies.policy_id` |
| `claim_date` | DATE | Date of loss (2019-01-01 … 2026-12-31) |
| `claim_year` / `claim_month` | INT | Year / month of loss |
| `yearfrac` | REAL | Years since 2019-01-01 (vet-cost inflation clock) |
| `condition` | TEXT | One of the 12 condition categories (see below) |
| `claim_cost` | REAL | Synthetic paid loss in USD (Gamma-distributed) |
| `brand`, `species`, `breed`, `breed_size`, `age`, `age_bin`, `state`, `territory` | — | Denormalized policy attributes at effective date |
| `has_note` | INT | 1 if the claim has a row in `claim_notes` (30,000 claims) |

### `claim_notes` — one row per synthetic free-text note (exactly 30,000 rows)

| Column | Type | Description |
|---|---|---|
| `note_id` | TEXT | Primary key, `NOTE-00000` … |
| `claim_id` | TEXT | FK → `claims.claim_id` |
| `category` | TEXT | True condition category (same 12 values as `claims.condition`) |
| `note_text` | TEXT | Templated synthetic clinical note |

### `policy_months` — mart helper (built by `src/build_db.py`, not generated)

One row per active policy-month: `policy_id`, `brand`, `month` (`YYYY-MM`),
`earned_premium` (that month's slice). Used by `kpi_01_monthly_loss_ratio.sql`.

## The 12 condition categories (exact, used everywhere)

1. Gastroenteritis
2. Skin Allergies
3. Ear Infection
4. Urinary Tract Infection
5. Dental Disease
6. Kennel Cough
7. Conjunctivitis
8. Laceration
9. Arthritis
10. Cruciate Ligament Tear
11. Hip Dysplasia
12. Diabetes

## Key metric definitions

| Metric | Definition |
|---|---|
| Loss ratio | `SUM(claim_cost) / SUM(earned_premium)` |
| Claim frequency | claims per 1,000 exposure-years |
| Average severity | `AVG(claim_cost)` |
| Deviance explained (pseudo-R²) | `1 − residual deviance / null deviance` of the GLM |
| Forecast MAPE | mean over the 12 holdout months of `\|forecast − actual\| / actual` on monthly loss ratio |
